# koishi-plugin-codex-reset

监控 [AIHOT Codex 重置 API](https://aihot.news/api/v1/codex-resets) 的 Koishi 插件。

## 功能

- 定时轮询 AIHOT 的 Codex / ChatGPT Work 重置事件快照。
- 支持推送新的重置预告、已确认的全员重置和重置卡事件。
- 目标支持平台 + 频道配置，例如 `onebot` + `123456789`。
- `codex.probability` / `重置概率`：基于历史快照计算经验概率。
- `codex.event` / `最近重置`：统计上一次已确认重置距今多少小时。
- `codex.calendar` / `重置日历`：生成本月的 PNG 日历图片，右侧详情固定为命令执行当天。
- `codex.history` / `重置历史`：生成公开重置事件的历史时间线图片。
- 日历中的 Tibo 头像作为本地资源随插件发布，不依赖用户访问 X 或运行时下载图片。

## 命令

命令目前都不接收额外参数：

- `codex.probability`，别名 `重置概率`：读取当前 API 快照，统计历史事件日率，并估算未来 24 小时和 7 天出现公开重置事件的概率。
- `codex.event`，别名 `最近重置`：显示上一次已确认重置发生时间、距今小时数、类型和事件名称。
- `codex.calendar`，别名 `重置日历`：发送本月日历 PNG；右侧详情固定显示命令执行当天（北京时间）的事件。
- `codex.history`，别名 `重置历史`：发送按北京时间排列的历史重置时间线 PNG。

日历和历史时间线命令需要安装并启用 `koishi-plugin-puppeteer`；概率、日历和历史命令都可以在配置中单独关闭。

首次轮询只建立本地基线，不会把 API 返回的历史事件全部推送；后续轮询只处理新增事件或 `announced` → `confirmed` 的状态变化。插件重启后会重新建立基线。

## 安装

```bash
npm install koishi-plugin-codex-reset
```

如果需要日历或历史时间线图片，再安装并启用 `koishi-plugin-puppeteer`。不安装 Puppeteer 时，监控、最近重置和概率分析仍然可以使用，图片命令会给出提示。

## 配置

- `监控接口地址`：监控 API 地址，默认 `https://aihot.news/api/v1/codex-resets`。
- `监控间隔`：轮询间隔，单位为秒，默认 300 秒。
- `请求超时时间`：单次 API 请求超时时间，单位为毫秒，默认 15000 毫秒。
- `推送目标`：推送目标表，填写“平台”和“频道或群组 ID”；平台留空会按频道尝试在线 Bot，同一平台/频道只发送一次。
- `推送重置预告`：是否推送预告。
- `推送已确认重置`：是否推送已确认的重置/重置卡事件。
- `艾特全体`：推送通知时是否艾特全体，默认关闭；需要目标平台支持全体艾特。
- `启用重置概率命令`：是否启用概率命令。
- `启用重置日历命令`：是否启用日历图片命令。
- `启用重置历史命令`：是否启用历史时间线图片命令。

API 是只读公开接口，不需要 API Key。插件使用 `ETag` 条件请求，并保留来源链接。请遵守 [AIHOT 公开使用规则](https://aihot.news/terms)：公开可访问不等于自动获得对外商业使用、镜像或转售授权。
